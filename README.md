

# AI-Based Online Review Authenticity Detection

## Overview

Online reviews play an important role in influencing customer decisions on e-commerce platforms, restaurants, hotels, and various online services. However, the increasing number of fake and misleading reviews has made it difficult for users to trust the information available online.

This project focuses on identifying and classifying fake reviews using Natural Language Processing (NLP), Machine Learning, and Deep Learning techniques. The system analyzes review text, extracts meaningful linguistic patterns, and predicts whether a review is genuine or deceptive.

As part of this study, multiple machine learning models such as Logistic Regression, Naive Bayes, Support Vector Machine (SVM), Random Forest, and XGBoost were implemented and compared. Deep learning approaches including BiLSTM and DistilBERT were also evaluated to understand their effectiveness in detecting fraudulent reviews.

The project follows a complete machine learning pipeline that includes data preprocessing, feature extraction, model training, performance evaluation, statistical analysis, and visualization of results. Various metrics such as Accuracy, Precision, Recall, F1-Score, ROC-AUC, and confusion matrices were used to compare model performance.

The goal of this project is to contribute toward building more trustworthy online platforms by helping identify misleading content and improving the reliability of user-generated reviews.

## Key Features

* Text preprocessing and cleaning using NLP techniques
* TF-IDF and linguistic feature extraction
* Multiple Machine Learning and Deep Learning models
* Comparative performance analysis
* Statistical significance testing
* Data visualization and reporting
* Fake vs Genuine review classification
